# ByteScope

> Technology, in perspective.

A premium technology and software publishing platform, built as a
commercially distributable template (Frontend Edition + Full-stack Pro
Edition) sharing one monorepo core.

See [docs/architecture.md](docs/architecture.md) for the monorepo layout and
[docs/roadmap.md](docs/roadmap.md) for build phases.
